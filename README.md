# 🍴 오늘 뭐 먹지? (What's for Dinner?)

저녁 메뉴 선택의 고민을 해결해주는 웹 서비스입니다.

## 🚀 주요 기능 (Features)
- **메뉴 추천 (Menu Recommendation):** 한식, 일식, 양식 등 다양한 메뉴를 무작위로 추천해줍니다.
- **다국어 지원 (Multi-language Support):** 한국어와 영어를 모두 지원합니다.
- **다크 모드 (Dark Mode):** 야간에도 눈이 편안하게 메뉴를 고를 수 있습니다.
- **반응형 디자인 (Responsive Design):** 모바일과 PC 어디서든 최적화된 화면을 제공합니다.

## 🛠 사용 기술 (Tech Stack)
- HTML5, CSS3, JavaScript (Vanilla JS)
- Custom Elements (Web Components)
- GitHub Pages (Deployment)
